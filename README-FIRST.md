WHERE IT ALL BEGAN — NEW ADMIN SITE

This rebuild gives you a private Admin Dashboard where you can:
- create/edit/delete stories
- publish or save drafts
- upload videos
- edit/delete videos
- choose categories/topics
- let visitors read published stories and watch published videos

SETUP:
1. Run supabase-setup.sql in Supabase SQL Editor.
2. Put these files into the root of your GitHub repository.
3. In assets/js/config.js paste your existing Supabase publishable/anon key.
4. Commit/push to GitHub Pages.
5. Go to login.html and sign in with your existing approved admin account.
6. Use Admin Dashboard.

IMPORTANT: Never put your Supabase service-role/secret key in the website.
Keep your existing site until this new version is tested.
