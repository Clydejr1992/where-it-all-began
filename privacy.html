YOUR PRIVACY MATTERS

Privacy

Every life has a story. People deserve to understand how their information is handled before sharing theirs.

About this website

Where It All Began is a project designed to help people preserve life stories, memories, and family history. This website is currently an early version, and its features are still being developed.

Story drafts

The current story form saves drafts in the visitor's browser using local browser storage. Drafts are not automatically uploaded to a server or published by this version of the website.

Anyone using a shared device should understand that another person with access to the same browser profile may be able to access locally saved drafts.

Contact form

The current contact form prepares a message in the visitor's email application. The visitor chooses whether to send that message. This website does not currently have a server-side contact submission system.

Public stories and interviews

Public story submissions, user accounts, file uploads, live interviews, and recording features are not currently connected. Before these features are introduced, the project should establish appropriate privacy notices, security safeguards, consent procedures, and ways to request corrections or removal.

Third-party services

This website is hosted through GitHub Pages and uses a custom domain. Hosting and domain providers may process technical information according to their own policies and applicable settings.

Questions

If you have questions about privacy, visit our Contact page.

Important: This is an initial privacy notice, not a complete legal privacy policy. It should be reviewed and updated before the website begins collecting or publishing personal stories.
