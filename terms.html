Terms of Use

These initial terms describe the current version of the Where It All Began website.

Current website

Where It All Began is currently a work in progress. Features may change, improve, or be replaced as the project develops.

Story drafts

The current story form allows visitors to create a draft that is stored locally in their browser.

This version does not automatically publish or submit those drafts to Where It All Began.

Stories and interviews

Public story submissions, live interviews, recordings, file uploads, and user accounts are not currently active features of this version of the website.

Future versions will need clear rules explaining ownership, permissions, publication, moderation, recordings, privacy, and removal requests.

Respectful use

Visitors should use the website respectfully and should not submit content that violates another person's rights or privacy.

Changes

These terms may be updated as the website develops and new features are introduced.

Contact

Questions about the website can be sent through the Contact page .

Important: These are starter terms for the current website and should be reviewed and updated by a qualified professional before the platform begins accepting public stories, recordings, payments, or other sensitive information.
